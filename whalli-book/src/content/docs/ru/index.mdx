## Почему Whalli?

<CardGrid>
  <Card title="Ворутины и каналы" icon="rocket">
    Кооперативная многозадачность с `wo` и `chan` — тысячи параллельных задач на фиксированном пуле потоков.
  </Card>
  <Card title="Современный HTTP бэкенд" icon="laptop">
    Фреймворк уровня Go `net/http`: REST-маршрутизация, middleware, Keep-Alive, статические файлы — полностью самодостаточен.
  </Card>
  <Card title="Единый SQL интерфейс" icon="document">
    Один API для SQLite (встроенный), PostgreSQL и MySQL — `sql.open`, `db.exec`, `db.query` с автотрансляцией параметров.
  </Card>
  <Card title="Батарейки в комплекте" icon="star">
    Продакшн-уровень LSP, плагин для VS Code, неблокирующий `mio` ввод-вывод и богатая стандартная библиотека.
  </Card>
</CardGrid>

## Пример — REST API со SQLite

```whalli
import http
import sql

let (db, _) = sql.open("sqlite", "app.db")
db.exec("CREATE TABLE IF NOT EXISTS tasks (id INTEGER PRIMARY KEY, title TEXT)")

let router = http.router()
router.use(http.cors())
router.use(http.logger())

router.get("/api/tasks", func(req) {
    let (rows, _) = db.query("SELECT * FROM tasks")
    return http.json_response(200, rows)
})

http.listen_and_serve(":8888", router)
```
