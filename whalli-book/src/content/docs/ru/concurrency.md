## Модель конкурентности

В Whalli реализован кооперативный планировщик задач M:N с алгоритмом распределения работы work-stealing на базе библиотеки `crossbeam-deque`. Легковесные зеленые потоки называются **ворутинами** (`wo`).

- **Нулевой оверхед по системным потокам**: Тысячи конкурентных ворутин исполняются на фиксированном пуле потоков ОС.
- **Неблокирующие операции**: Задачи уступают выполнение при вызовах `time.sleep`, операциях с каналами, системных событиях ввода-вывода и блокировках мьютексов.
- **Выделенный поллер I/O и таймеров**: Фоновый поток непрерывно обрабатывает события `mio::Poll` и каналы таймеров.

## Ворутины (`wo`) и дескрипторы задач (`TaskHandle`)

Запуск функции в отдельной ворутине выполняется с помощью ключевого слова `wo`:

```whalli
import time

func worker(id: int) {
    for i in range(1, 4) {
        time.sleep(0.1)
        println(f"Воркер {id} шаг {i}")
    }
}

wo worker(1)
wo worker(2)
```

Выражение `wo func(...)` возвращает объект дескриптора задачи (`TaskHandle`). С его помощью можно отслеживать статус задачи, дожидаться результата и безопасно изолировать сбои:

```whalli
func calculate(a: int, b: int) -> int {
    return a + b
}

let task = wo calculate(20, 22)

// 1. Ожидание через метод .result() -> (res, err)
let (res, err) = task.result()
println("Результат:", res) // 42

// 2. Ожидание через оператор чтения канала '<-'
let task2 = wo calculate(10, 5)
let (val, _) = <- task2

// 3. Проверка статуса выполнения без блокировки
if task.is_done() {
    println("Статус:", task.status()) // "completed" или "failed"
}
```

Если внутри ворутины возникнет ошибка выполнения (деление на ноль, паника), основной процесс не завершится аварийно — ошибка будет локализована в дескрипторе и вернется через `err` в `task.result()`, при этом все зарегистрированные `defer` гарантированно исполнятся.

## Каналы (`chan`)

Каналы служат для безопасной передачи типизированных сообщений между ворутинами.

```whalli
import time

let ch = new(chan, 5) // буферизованный канал на 5 сообщений

wo func() {
    for i in range(1, 4) {
        time.sleep(0.2)
        ch <- f"сообщение #{i}"
    }
    ch.close()
}()

// Цикл чтения сообщений
while true {
    let msg = <- ch
    if msg == nil {
        break
    }
    println("Получено:", msg)
}
```

## Оператор `select`

Мультиплексирование нескольких каналов и тайм-аутов:

```whalli
import time

let ch1 = new(chan, 1)
let ch2 = new(chan, 1)

let result = select {
    msg <- ch1 => f"канал 1: {msg}",
    msg <- ch2 => f"канал 2: {msg}",
    <- time.after(1.0) => "таймаут через 1 секунду",
    default => "ни один канал не готов сразу",
}
```

## Синхронизация (`sync`)

```whalli
import sync

// 1. WaitGroup (счетчик завершения задач)
let wg = sync.WaitGroup()
wg.add(2)

wo func() {
    // выполнение задачи 1
    wg.done()
}()

wo func() {
    // выполнение задачи 2
    wg.done()
}()

wg.wait() // ожидает, пока счетчик не станет равен 0

// 2. Mutex (взаимная блокировка)
let mu = sync.Mutex()
mu.lock()
// критическая секция
mu.unlock()

let acquired = mu.try_lock() // неблокирующая попытка взятия замка
if acquired {
    mu.unlock()
}
```
