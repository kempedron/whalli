## Официальное расширение для VS Code

Whalli поставляется с полноценной поддержкой сред разработки **VS Code** и **VSCodium** (исходники в каталоге `whalli-vscode/`).

### Возможности расширения

- **▶️ Запуск в один клик**: Мгновенный запуск скрипта кнопкой на панели редактора или сочетанием клавиш `Ctrl+F5`.
- **IntelliSense и автодополнение**: Контекстные подсказки по ключевым словам, встроенным типам, модулям стандартной библиотеки (`http.`, `sql.`, `net.`, `fs.`, `time.`, `math.`) и пользовательским функциям.
- **Всплывающая документация (Hover)**: Подробные сигнатуры функций, описание параметров и примеры вызовов.
- **Диагностика в реальном времени**: Подсветка синтаксических ошибок и неверных импортов прямо во время набора кода.
- **Inlay Hints**: Подсказки выведенных типов прямо в строке кода (`let count = 42` отображает `: int`).
- **Переход к определению (`F12`)**: Быстрая навигация к объявлениям функций, структур и методов.
- **Форматирование документа (`Shift+Alt+F`)**: Автоматическое выравнивание и оформление кода.

## Сервер `whalli-lsp`

Языковой сервер скомпилирован в виде отдельного легковесного бинарника, взаимодействующего по стандарту JSON-RPC через стандартные потоки ввода-вывода (`stdio`). Его можно подключить к любому современному редактору с поддержкой LSP (Neovim, Emacs, Helix, Sublime Text).
