**Whalli** — это лёгкий, динамически типизированный язык программирования с нативной кооперативной многозадачностью, неблокирующим вводом-выводом и полноценным набором инструментов разработчика. Эталонная реализация представляет собой стек-байткод виртуальную машину, написанную на Rust (`edition 2024`).

## Цели дизайна

- **Минимальный оверхед рантайма**: единый пул потоков с алгоритмом work-stealing, без создания отдельного потока ОС на каждую задачу.
- **Кооперативная многозадачность из коробки**: ворутины (`wo`) и каналы (`chan`) являются примитивами языка, а не внешними библиотеками.
- **Неблокирующий ввод-вывод на `mio`**: сетевой стек `net` и веб-сервер `http` используют системный опрос событий ОС (epoll/kqueue) без блокировки рабочих потоков планировщика.
- **Самодостаточный бэкенд-стек**: функционал уровня Go `net/http` с поддержкой Keep-Alive, удобным REST-роутером, цепочками middleware и универсальным интерфейсом к БД (`sqlite`, `postgres`, `mysql`).
- **Интегрированные инструменты**: сервер Language Server Protocol (LSP) и расширение для VS Code поставляются вместе с компилятором.
